# Investigation 001 — Windows Failed Login Analysis

## Status

Planned / In Progress.

## Scenario

Analyze repeated failed authentication activity generated in an authorized Windows lab environment.

## Primary Evidence Source

Windows Security Event Log — Event ID **4625** (failed logon).

## Investigation Questions

1. Which account experienced the failed logons?
2. How many failed attempts occurred?
3. What logon type was involved?
4. What source workstation or network address is recorded?
5. Did a successful logon occur after the failures?
6. Does the pattern look like user error or suspicious repeated authentication activity?
7. What containment or escalation action would be appropriate?
